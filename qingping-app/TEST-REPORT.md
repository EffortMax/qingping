# 清屏 v1.1.0 实机验证报告

验证时间：2026-10-21 17:16-17:20（本机）
环境：MuMu Player 12 模拟器（Android 12 / SDK 32，1920x1080）
构建：本机 JDK 17 + Gradle 8.7 wrapper + Android SDK 34，`BUILD SUCCESSFUL`
安装：`adb install` 成功，无障碍服务经 `settings put secure enabled_accessibility_services` 启用

## 一、v1.0 乱点的根因（已定位并修复）

| # | 缺陷 | 后果 |
|---|---|---|
| 1 | 默认关键词含“关闭”“知道了”，且用**包含匹配** | 任何界面出现“关闭/知道了”即被点击 —— 用户“切屏也乱点”的直接原因 |
| 2 | 任意时刻、任意界面都扫描 | 浏览、聊天、列表页都被介入 |
| 3 | 误触返回判据为“1.5 秒内换包名” | 用户主动切应用被误判成误触，被强制按返回 |

## 二、v1.1 的四重闸门

1. **时间闸门**：仅在新应用启动后 6 秒内工作，平时不扫描
2. **关键词闸门**：归一化后**完全相等**匹配白名单（跳过/关闭广告/Skip…），“关闭”“知道了”已彻底移除
3. **形态闸门**：必须可见、可点、面积 < 屏幕 20%，排除输入框与正文
4. **频次闸门**：一次开屏最多 1 次，全局 1.5 秒冷却
   另外：系统界面/桌面/输入法/权限弹窗/设置页进黑名单；误触返回仅在“清屏自己点击后 1.2 秒内被带走”时触发

## 三、实测结果

自检 APP（`com.qingping.selftest`，独立包名，与清屏隔离）

### 正向：应跳过
开启 `mode=ad` 假开屏页（右上角“跳过 5”按钮）后的 logcat：

```
17:16:53.245  I QPSELFTEST: OPENED:ad
17:16:53.387  I QPSELFTEST: CLICKED:跳过      ← 142ms 后自动点击
```

首页“累计跳过开屏”计数 = **1**，证明 Room 统计落库正常。

### 反向：绝不应点（本次修复的核心）
开启 `mode=normal` 普通页，页面含 6 个陷阱按钮：
`关闭` / `知道了` / `取消` / `确定` / `关闭广告位说明` / `跳过片头设置`

观察 20 秒（已超过 6 秒安全窗口）后的 logcat：

```
17:17:01.948  I QPSELFTEST: OPENED:normal
（此后无任何 CLICKED 记录）
```

窗口焦点始终未被夺走：`mCurrentFocus=Window{... com.qingping.selftest/...SelfTestActivity}`

**结论：v1.0 的乱点行为在 v1.1 中消失。**

## 五、已知边界（诚实说明）

1. **纯图片按钮**不处理 —— 宁可漏点也不乱点
2. **6 秒窗口**：若某 APP 开屏广告超过 6 秒才出现“跳过”，会漏点（可调大常量 `SAFE_WINDOW_MS`）
3. **摇一摇广告**无法阻止触发，只能事后返回
4. 弹窗右上角的 **X 图标**（无文字）不在白名单内 —— 是否支持需要你确认（高风险，建议默认关闭）
5. `force-stop` 应用会使系统解绑无障碍服务，需重新开启（安卓原生行为）
